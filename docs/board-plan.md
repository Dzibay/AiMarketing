# Доска кампании: пошагово, совпадает с Директом, точечная перегенерация

План от 2026-11-20 по ответам владельца на 15 вопросов. Заменяет решение «подробный бриф — одна доска, одно
согласование» (docs из 2026-11-16): теперь шаги согласуются по одному и сразу пишутся в черновик Директа.

## Решения владельца

## Что нашлось по скриншотам

- **Доска — не Директ.** Она складывается из таблиц чата и правок; после черновика не читает кампанию. Отсюда
  «0 из 7» у групп, у которых в Директе объявления есть.
- **«Группа / Объявление 2»** (так промпт велит называть второе объявление) доска понимает как отдельную группу:
  заголовки уезжают в «новую группу», у настоящей — пусто, групп на доске 54 при 60 фразах.
- **Колонки таблиц ИИ не проверяются по смыслу:** в первую ячейку попадают подписи «Заголовок 1»/«Текст 1»,
  во вторую у фраз — название группы вместо частотности («станок чпу купить · Производство — станки»).
- **Лимиты не жёсткие:** 14 заголовков из 7 и 6 текстов из 3 проходят как согласованные.

## План (пункты нумерованы — «Давай пункт N»)

### 1. Чистые данные доски (быстро, независимо от остального)

_Сделано 2026-11-20._ Таблица ИИ с «Заголовок N» и т. п. в первой ячейке не принимается; название группы во второй
ячейке фраз стирается; объявления и картинки — только в группы с доски, без «/ Объявление N»; вместе с
согласованными не больше 7 заголовков и 3 текстов; «Готовность» краснеет (`limits`), согласование доски
заблокировано и на сервере. Старые доски: «/ Объявление N» склеено с группой, подписи скрыты.

- Сервер отклоняет строки-заглушки: «Заголовок N», «Текст N», «Быстрая ссылка N», «Уточнение N» и пустые
  подписи — ИИ получает ошибку и пишет настоящий текст.
- Вторая ячейка фразы, совпадающая с названием группы, не считается частотностью.
- «Группа / Объявление 2» — второе объявление той же группы, а не новая группа. Доска показывает объявления
  группы карточками «Объявление 1, 2».
- Больше 7 заголовков / 3 текстов в одном объявлении — не согласовать (красный счётчик + кнопка заблокирована).
- Старые чаты: доска при чтении склеивает «… / Объявление N» с группой и прячет заглушки.

### 2. Черновик с первого шага, доска читает Директ
- После согласования шага «Бриф» создаётся черновик кампании (имя, гео, бюджет, стратегия по брифу — шаг
  «Настройки» потом их уточняет). Каждый следующий «Дальше» дописывает шаг в этот черновик.
- Доска показывает кампанию из Директа (группы, фразы, объявления, расширения, настройки) плюс поверх —
  предложения ИИ, ещё не согласованные. Галочка ✓ у строки = она есть в Директе.
- Черновик сам не запускается, на модерацию отправляет пользователь (принцип «только с согласия» не меняется).
- Для уже созданных кампаний доска открывается со страницы кампании — тот же вид, без шагов сборки.

### 3. Мастер по шагам

_Сделано 2026-11-20 (без записи в Директ — это пункт 2)._ Доска — мастер из 8 шагов; «Дальше» согласует
отмеченное и сразу просит ИИ следующий шаг, «Переделать» — с комментарием, «Пропустить» — у необязательных
(картинки, расширения, отдельная таблица минус-фраз/аудиторий). «Дальше» заблокирована красными `limits`,
`images`, `extras`. Прошлый шаг открывается и правится через «Что переделать» (ИИ пришлёт таблицу с revise).
Сборка одной доской осталась только для старых чатов (`by_stages=false` явно).
- Шаги: Бриф → Спрос → Группы и фразы (+ минус-фразы) → Объявления → Картинки (можно пропустить) →
  Расширения → Настройки → Проверка и модерация. Аудитории — необязательным блоком в «Группах», включается
  в режиме эксперта.
- Открыт только текущий шаг; прошлые свёрнуты с ✓ и кратким итогом («12 групп · 140 фраз»), их можно открыть
  и поправить; будущие серые.
- Внизу шага одна кнопка «Дальше» (= записать в Директ и попросить ИИ следующий шаг) и «Пропустить», где
  шаг необязателен. «Дальше» недоступна, пока у шага есть красные проверки (пустая группа, лимиты, требования
  брифа).
- Убираем режим «одна доска — одно согласование» и плашки «на доске / ждёт решения».

### 4. Правки и сверка с Директом
- Правки в уже записанных шагах (руками или перегенерацией) копятся; сверху доски — «Применить в Директ
  (N изменений)» со списком, что изменится, и «Сбросить».
- При открытии доски и раз в несколько минут, пока она открыта, — лёгкая сверка с Директом (изменённые
  объекты). Если кампанию правили в Директе: плашка «В Директе изменилось: …» и кнопка «Подтянуть»; при
  конфликте с несохранёнными правками — показать обе версии.
- ИИ видит состояние доски = Директ + очередь правок, а не историю чата.

### 5. Точечная перегенерация
- Кнопка ↻ у: заголовков объявления, текстов объявления, одной строки (заголовок/текст), фраз группы,
  минус-фраз, быстрых ссылок, уточнений. Не у брифа и настроек — там поля формы.
- По клику — необязательное поле «что не так» и 3–5 новых вариантов рядом со старыми; выбранные заменяют
  старые и попадают в очередь «Применить в Директ».
- Дёшево: не агентный цикл чата, а один короткий вызов модели с минимальным контекстом (бриф одной
  строкой, фразы группы, текущие варианты, запреты из брифа, лимиты знаков), без инструментов и истории.
  Списывается из лимита как обычный запрос; сервер проверяет длины и запреты, лишнее отбрасывает.

### 6. Бриф формой
- Шаг 1 — форма: сайт, что рекламируем, регион, бюджет в неделю, цель/конверсия, ограничения (запрещённые
  слова, обязательные минимумы). Кнопка «ИИ заполнит по сайту» заполняет форму, пользователь правит.
- Вопросы ИИ в чате на этом шаге не нужны; ссылка с ref — по-прежнему карточкой выбора.

### 7. Чат рядом с доской
- Доска — основная область; чат — боковая панель, свёрнута по умолчанию (на телефоне — панель снизу).
- После каждого шага в чате одна строка итога с кнопкой: «Готово: 5 групп, 35 заголовков → Шаг 4 на доске».
  Шаги «посмотрел…» свёрнуты в одну строку «ИИ смотрел: 6 источников».
- Пустых ответов нет: если ИИ закончил без текста, сервер подставляет итог шага.
