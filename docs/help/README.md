# Справка кабинета

Статьи раздела «Справка» (`/cabinet/help`). Кабинет собирает их при сборке фронтенда (`frontend/src/utils/help.js`),
а ИИ-помощник читает их инструментом `help_search` (`backend/app/help.py`) и отвечает по ним на вопросы о сервисе.
Поэтому папка копируется в оба образа — фронтенда и бэкенда. Пишите так, чтобы абзац читался и без соседних:
ИИ получает статью целиком, но цитирует кусками.

Файл — одна статья, имя файла — её адрес: `undo.md` → `/cabinet/help/undo`. В начале — шапка:

```
---
title: Как вернуть как было
summary: Одна строка для списка статей и поиска.
sections: history
order: 4
---
```

- `sections` — разделы меню (`route.meta.section`), для которых кнопка справки (книжка) у заголовка страницы открывает эту
  статью. У раздела — одна статья.
- `order` — место в списке.
- Текст — тот же Markdown, что в ответах ИИ (`utils/markdown.js`): заголовки `##`, списки, **жирный**, ссылки.
  Ссылки на экраны кабинета пишутся путём: `[Подключения](/cabinet/connections)`.

`changelog.md` — «Что нового». Запись начинается заголовком `## ГГГГ-ММ-ДД · Заголовок`, свежая — сверху.
Дата записи — её метка: пока пользователь не открыл свежую запись, на колокольчике горит точка.

`glossary.md` — вступление к словарю; сами термины берутся из `frontend/src/utils/glossary.js` (те же, что в
подсказках «?» рядом с цифрами). Этот README в справку не попадает.
