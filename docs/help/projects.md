**Проект** — один сайт. В нём собраны счётчик Метрики этого сайта, кампании Директа, которые ведут на него, и вся статистика по ним.

Проекты появляются сами: на каждый счётчик Метрики из подключённого аккаунта — свой. Кампании раскладываются по проектам по счётчику, указанному в их настройках.

## Подготовим проект

После «Добавить сайт» открывается окно из пяти коротких шагов: клиент, главная цель, цена заявки и бюджет, шаблон ссылки, описание бизнеса. Любой шаг можно пропустить. Цели Метрики могут появиться через минуту после добавления сайта.

Кнопка **«ИИ прочитает сайт»** составит описание бизнеса по сайту. Она расходует немного лимита ИИ, поэтому запускается только по нажатию.

Пока у проекта нет цели или шаблона ссылки, на сводке видна карточка «Проект готов на N из 5» с кнопкой «Доделать».

## Бюджет на месяц

На главной проекта есть блок **«Бюджет на месяц»**: полоса «план — факт — прогноз» и отметка, сколько по плану должно уйти к сегодняшнему дню. Фраза под заголовком отвечает на главный вопрос: «При таком темпе уйдёт около 86 000 ₽ из 80 000 ₽» или «Уложитесь».

Прогноз учитывает дни недели: если в выходные реклама тратит меньше, сервис это знает по последним неделям. Пока истории расхода меньше четырёх недель, прогноз делит поровну по дням.

Бюджета нет — задайте его прямо в блоке. «Изменить бюджет» меняет сумму там же. Если деньги уходят быстрее плана, появится кнопка **«Попросить ИИ уложиться в бюджет»** — она откроет чат проекта с готовой просьбой. Лимит ИИ расходуется только по нажатию.

## Все проекты или один

Список проектов в меню слева — это фильтр. «Все проекты» показывают каждый раздел сразу по всем сайтам, выбранный проект — только по нему. На телефоне проект выбирается в верхней строке.

## Настройки проекта

Шестерёнка рядом с выбранным проектом открывает его настройки:

- **Основное** — цель (заявка или покупка) и KPI: сколько готовы платить за заявку или какую долю выручки отдавать на рекламу. С ними сервис сравнивает результат.
- **О бизнесе** — что продаёте, где, что точно не ваше. Это читают ИИ и разбор запросов.
- **Помощник** — тон текстов и заметки для ИИ: что нельзя трогать, особенности.

В экспертном режиме там же — доступ ИИ, его память, кабинеты Директа и шаблон ссылки.

**«Взять из проекта…»** под разделами настроек переносит настройки другого вашего проекта: шаблон ссылки, тон и обращение ИИ, модель, доступ ИИ, главный показатель, защиту бюджета, заметки и запомненные ответы. Отметьте нужное — по каждому пункту видно «было → станет». Домен в шаблоне ссылки заменится на адрес этого сайта.

## Настройки для новых проектов

**Настройки → «Для новых проектов»** — что получит каждый новый сайт: главный показатель, модель ИИ и защиту бюджета, в экспертном режиме ещё шаблон ссылки (домен подставится сам) и доступ ИИ. Уже созданные проекты не меняются.

Когда вы впервые сохраняете такую настройку в проекте, под ней появится вопрос **«Сделать так по умолчанию?»**. «Да» — так настроятся новые проекты, «Нет» — вопрос больше не появится.
