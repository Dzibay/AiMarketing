## Вход через Яндекс

Директ и Метрика подключаются через официальную страницу Яндекса. Пароль от Яндекса сервис не получает — только доступ к API, который вы подтверждаете. Доступ хранится зашифрованным и используется только для работы сервиса от вашего имени.

## Что сервис может менять

- Без вашего «Выполнить» ИИ ничего не меняет в Директе.
- Исключения — то, что вы сами разрешили в настройках проекта → «Доступ ИИ», и правила автопилота, которые вы включили.
- Каждое изменение записано в [Историю](/cabinet/history) с автором и откатывается.

## Деньги

Рекламный бюджет вы платите Яндексу напрямую — через сервис он не проходит. Тариф оплачивается через ЮKassa, данные карты сервис не видит.

## Как отозвать доступ

- В [Подключениях](/cabinet/connections) — отключить аккаунт.
- В Яндексе: Яндекс ID → «Безопасность» → «Устройства и сервисы».

Как мы обращаемся с данными — в [политике конфиденциальности](/privacy).
