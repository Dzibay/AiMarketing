# Промпты для макетов интерфейса

Как пользоваться:

1. Подходит любой генератор интерфейсов: v0, Lovable, Bolt, Figma Make, Claude (артефакт). Для генераторов
   картинок уберите первую строку про React.
2. Каждый вариант раскладки — один промпт целиком: в нём уже есть общий контекст и данные. Чтобы сравнение
   было честным, генерируйте все три в одном инструменте.
3. После выбора варианта отправьте в тот же чат промпты из раздела «Дополнительные экраны» — они опираются на
   уже сгенерированный макет.

## Вариант A — постоянное меню слева

```text
Сделай кликабельный макет веб-приложения: React + Tailwind, данные зашиты в код, без бэкенда. Весь интерфейс на русском. Нужны 2 экрана с переключением между ними, светлая и тёмная тема.

О ПРОДУКТЕ
AiMarketing — сервис для ведения рекламы в Яндекс Директе и аналитики Яндекс Метрики с ИИ-помощником. Пользователи: директологи-фрилансеры с 5–20 клиентами и владельцы бизнеса с одним сайтом, многие не технари. Главная ценность — ИИ-чат: он разбирает кампании, находит, что сливает бюджет, и предлагает изменения. Ни одно изменение не применяется без кнопки «Выполнить». Второе по важности — сводка по всем проектам и список кампаний.

ПОНЯТИЯ
- Проект — один сайт со счётчиком Метрики и его кампании Директа.
- Клиент — необязательная папка для проектов (нужна фрилансеру; у владельца бизнеса клиентов нет, и тогда слово «клиент» нигде не видно).
- Подключения — логины Яндекса, через которые сервис видит Метрику и Директ.

РАЗДЕЛЫ (одни и те же всегда; выбранный проект фильтрует данные, «Все проекты» — по всем сразу)
- Сводка — стартовая страница: расход сегодня / вчера / 7 дней, конверсии, CPA или ДРР против цели, «Где горит» (проблемы по важности), карточки проектов со спарклайнами.
- ИИ-помощник — общий чат по всем проектам и чаты внутри проектов, готовые сценарии («Разбери кампании», «Почисти запросы», «Собери новую кампанию»).
- Кампании — таблица с фильтрами и массовыми действиями (пауза, запуск, бюджет, копия).
- Чистка запросов — ИИ размечает поисковые запросы «наше / не наше», пользователь подтверждает минус-фразы пачкой.
- Аналитика — динамика, площадки РСЯ, объявления.
- Автопилот — правила («если CPA выше 600 ₽ три дня подряд — пауза и уведомление») и эксперименты ИИ.
- История — журнал изменений (кто сделал: вы, ИИ, правило) с кнопкой «Вернуть как было».
- Настройки проекта.
- Служебные: Подключения, Настройки (профиль, уведомления в Telegram), Тариф.

ПОСТОЯННЫЕ ЭЛЕМЕНТЫ
- Переключатель проекта: «Все проекты» и список «Клиент → его проекты» с поиском.
- Шкала лимита на месяц — без денег и токенов: «Использовано 62% · тариф Про до 12 декабря». По клику — детализация.
- Счётчик «Ждёт решения: 5» — предложения ИИ, которые ждут подтверждения во всех проектах.
- Кнопка поддержки (чат с оператором) в правом нижнем углу.
- Профиль, переключатель темы.

СТИЛЬ
Спокойный, понятный новичку, много воздуха. Светлая тема: фон #eef3ef (мятный), карточки белые, акцент #1f6f4a. Тёмная: фон #131915, карточки #1d2420, акцент #74dca4. Шрифт Onest. Скругления 14px, мягкие тени. KPI-карточки со спарклайнами, плавные графики с заливкой. Статусы: зелёный — в цели, жёлтый — внимание, красный — проблема. Минимум терминов, подсказки «?» у сложных понятий.

ДАННЫЕ ДЛЯ МАКЕТА
- Клиент «Окна Профи»: проект okna-profi.ru — расход сегодня 4 820 ₽, 12 конверсий, CPA 402 ₽ при цели 450 ₽; проект msk.okna-profi.ru — 1 950 ₽, 3 конверсии, CPA 650 ₽ при цели 450 ₽.
- Клиент «Стоматология Улыбка»: ulybka-dent.ru — 6 300 ₽, 5 конверсий, CPA 1 260 ₽ при цели 1 000 ₽.
- Без клиента: shop-kofe.ru (интернет-магазин) — 2 100 ₽, ДРР 14% при цели 18%.
- «Где горит»: «ulybka-dent.ru — CPA выше цели на 26%, третий день»; «okna-profi.ru — денег на балансе на 2 дня»; «shop-kofe.ru — 2 объявления отклонены модерацией»; «msk.okna-profi.ru — кампания „Окна ПВХ — РСЯ“ потратила 3 400 ₽ за неделю без конверсий».

ВАРИАНТ РАСКЛАДКИ — «ПОСТОЯННОЕ МЕНЮ СЛЕВА»
Слева постоянное меню с иконками и подписями (можно свернуть до иконок). Наверху меню — переключатель проекта. Ниже пункты: Сводка, ИИ-помощник, Кампании, Чистка запросов, Аналитика, Автопилот, История, Настройки проекта (серая с подсказкой «Выберите проект», когда выбраны «Все проекты»). Внизу меню: Подключения, Настройки, Тариф. Меню не меняется ни при каких переходах. Шапка страницы: заголовок, шкала лимита, «Ждёт решения», профиль.

Экран 1 — Сводка, выбраны «Все проекты»: ряд KPI-карточек, блок «Где горит», карточки проектов, сгруппированные по клиентам.
Экран 2 — ИИ-помощник, выбран проект okna-profi.ru: слева от переписки список чатов этого проекта и «Общий чат». В переписке: вопрос пользователя «Почему выросла цена заявки на прошлой неделе?», ответ ИИ с короткими выводами и мини-графиком, ниже карточка предложения «Снизить ставки в 3 группах на 15%» с таблицей «было → станет» и кнопками «Выполнить» и «Отклонить». Над полем ввода — выбор модели: «Быстрая ●○○», «Стандартная ●●○», «Думающая ●●●» (точки — сколько лимита тратит ответ).
```
