[Минус-слова](/slovar/minus-slova/) — самый дешёвый способ сэкономить в Директе. И самый простой способ потерять заявки, если перестараться.

## Два этапа

**До запуска** собирают базовый список: то, что точно не нужно почти никому. Бесплатное, вакансии, учёба, «своими руками». Для этого подойдёт [генератор минус-слов](/instrumenty/generator-minus-slov/).

**После запуска** — главная работа. Только в отчёте по [поисковым запросам](/slovar/poiskovye-zaprosy/) видно, что на самом деле ищут люди, которые кликают по вашим объявлениям.

## Где задавать

- У отдельной [ключевой фразы](/slovar/klyuchevaya-fraza/) — когда слово лишнее только для неё.
- У группы или кампании — когда слово лишнее для всех фраз.
- В общем списке — когда один набор нужен нескольким кампаниям.

## Как не отрезать заявки

1. **Проверяйте конфликт с фразами.** Минус-слово, которое есть в вашей же ключевой фразе, отключит её показы.
2. **Не минусуйте по одному клику.** Запрос без конверсии за один клик — ещё не мусор.
3. **Используйте минус-фразы.** Если «бесплатно» само по себе нужное («бесплатная доставка»), минусуйте сочетание, а не слово — см. [минус-фразы](/slovar/minus-frazy/).
4. **Учитывайте формы.** «Бу» и «б у» — для поиска это может быть одно и то же, а для списка — нет.

## Как часто разбирать

Новой кампании — раз в несколько дней первые две недели, потом — раз в неделю. Чем дольше пауза, тем длиннее список и тем больше потрачено.

## Как это делает Толк

Запросы всех кампаний проекта собираются в одну очередь. ИИ подписывает ярлыки — «нецелевой», «информационный», «целевой» — и объясняет почему, а решение принимаете вы. Толк проверяет, не конфликтует ли минус-слово с вашими фразами, и запоминает решения — тот же запрос не придётся разбирать снова.
